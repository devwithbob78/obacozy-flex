# Obacozy-Flex Furniture Catalogue

A responsive, static furniture catalogue website for GitHub Pages.

## What's included
- Supplied catalogue photographs grouped into clear collections: sofas & lounge, bedroom, kitchen, dining, TV & media, tables, storage & display, and bar & wine.
- Separate craftsmanship section for framework/workshop and installation photographs.
- Additional Unsplash interior inspiration images, clearly labelled as illustrative and not client projects.
- Click-to-enlarge photo grid, category filters, and WhatsApp enquiry links with product-specific pre-filled messages.
- No public prices; customers can discuss and negotiate directly on WhatsApp.

## Deploy to GitHub Pages
1. Create a public GitHub repository named `obacozy-flex`.
2. Upload `index.html`, `README.md`, and the entire `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. The site URL will be `https://YOUR-GITHUB-USERNAME.github.io/obacozy-flex/`.
